# 📚 Caderno Temático - Python para Análise de Dados com NotebookLM

## 📌 Sobre o projeto

Este repositório foi desenvolvido como parte do desafio **Criando um Caderno Temático com NotebookLM** da DIO.

O objetivo é utilizar a Inteligência Artificial como ferramenta de aprendizagem para organizar estudos, produzir resumos, criar um glossário e desenvolver habilidades de Engenharia de Prompts.

---

# 🎯 Objetivos

- Aprender Python aplicado à Análise de Dados;
- Desenvolver habilidades utilizando o NotebookLM;
- Organizar os estudos de forma estruturada;
- Criar um material para futuras revisões;
- Compartilhar o aprendizado através do GitHub.

---

# 📚 Tema de estudo

**Python para Análise de Dados**

O conteúdo estudado é baseado principalmente no livro **Python para Análise de Dados**, de Wes McKinney, além da documentação oficial do Python, Pandas e NumPy.
