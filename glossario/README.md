# 📖 Glossário

Este glossário reúne os principais conceitos aprendidos durante os estudos de Python para Análise de Dados.

---

# Python

Linguagem de programação de alto nível, conhecida por sua simplicidade, legibilidade e ampla utilização em ciência de dados, automação, desenvolvimento web e inteligência artificial.

---

# DataFrame

Estrutura de dados bidimensional da biblioteca Pandas, semelhante a uma tabela, composta por linhas e colunas.

---

# Series

Estrutura de dados unidimensional do Pandas, utilizada para representar uma única coluna de dados.

---

# Pandas

Biblioteca Python especializada em manipulação, limpeza e análise de dados.

---

# NumPy

Biblioteca destinada à computação numérica de alto desempenho, utilizando estruturas chamadas Arrays.

---

# Matplotlib

Biblioteca utilizada para criação de gráficos e visualização de dados.

---

# Seaborn

Biblioteca construída sobre o Matplotlib que facilita a criação de gráficos estatísticos mais elegantes.

---

# CSV

Formato de arquivo utilizado para armazenar dados tabulares separados por vírgulas.

---

# Jupyter Notebook

Ambiente interativo que permite desenvolver códigos Python juntamente com textos, imagens e gráficos.

---

# Biblioteca

Conjunto de funções e recursos prontos que podem ser utilizados em programas Python.

---

# Engenharia de Prompts

Técnica utilizada para elaborar instruções claras e objetivas para que a Inteligência Artificial produza respostas mais precisas.

---

# NotebookLM

Ferramenta de Inteligência Artificial desenvolvida pelo Google para organização de estudos, análise de documentos e geração de resumos com base em fontes fornecidas pelo usuário.

---

# Conclusão

A construção deste glossário facilitou a revisão dos conceitos fundamentais relacionados ao estudo de Python para Análise de Dados.
