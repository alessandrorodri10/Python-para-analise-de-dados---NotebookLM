## 2. NumPy

Principais recursos:

- Arrays
- Operações matemáticas
- Álgebra linear
- Estatística
- Geração de números aleatórios

Exemplo:

```python
import numpy as np

dados = np.array([10,20,30,40])

print(dados.mean())
```

---

## 3. Pandas

Principais recursos:

- DataFrames
- Series
- Leitura de arquivos CSV
- Seleção de dados
- Filtros
- Agrupamentos
- Ordenação

Exemplo:

```python
import pandas as pd

df = pd.read_csv("clientes.csv")

print(df.head())
```

# 💡 Boas Práticas

✔ Utilizar nomes significativos para variáveis.

✔ Comentar apenas quando necessário.

✔ Organizar o código em funções.

✔ Tratar valores ausentes.

✔ Validar os dados antes da análise.

✔ Documentar os projetos.

# ⚠ Erros Comuns

- Esquecer de importar bibliotecas.

- Misturar tipos de dados.

- Não tratar valores nulos.

- Alterar DataFrames sem fazer cópias.

- Não documentar o código.
